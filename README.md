# Request Simulation

## Overview

`RequestSimulation.js` is used to simulate client requests to the load balancing testbed. It helps test how the load balancer distributes requests across backend servers.

## Prerequisites

- Node.js
- The load balancing testbed running locally

## Usage

Run the script with:

```bash
node RequestSimulation.js
```

Make sure the load balancing testbed is running before starting the simulation.

## Purpose

The script can be used to observe request handling and evaluate the behaviour of the load balancing system under simulated traffic.
